# Frame Endpoint Rules

## I2VA
The opening image establishes the initial visual state.

## FL2VA
The motion must plausibly connect the first image to the last image.

## L2VA
The prompt must describe a plausible preceding state that reaches the supplied final image.

## Endpoint lock

Do not describe an ending state that conflicts with the supplied final frame.

Do not describe a starting state that conflicts with the supplied first frame.
