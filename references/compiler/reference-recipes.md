# Reference Recipes

These recipes define HOW to use references. They do not authorize new story content.

## Identity image + motion video + voice audio

- image reference = identity / appearance;
- video reference = motion/camera reference only;
- audio reference = voice timbre/delivery only;
- keep the target subject identity stable;
- do not import unrelated source identity, environment, props, or dialogue.

## Environment + character references

Keep environment and character responsibilities separate unless the user explicitly requests attribute transfer.

## Multiple people

Give each distinct person a distinct semantic subject label. A media slot is not automatically a character identity.

## Attribute transfer

When the user explicitly transfers one attribute from one reference to another, lock only that attribute. Do not copy the source reference wholesale.

## Reference priority

Current user role assignments override assumptions from filenames, slot order, visual similarity, or historical examples.
