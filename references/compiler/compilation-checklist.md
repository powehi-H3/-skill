# Compilation Checklist

Internal checklist only.

1. What exactly did the user request?
2. What must be preserved?
3. What is the H3 mode?
4. What references exist and what is each reference's role?
5. Which official schema applies?
6. Which user semantics need concrete language compilation?
7. What remains intentionally unspecified?
8. Are there state or timing dependencies?
9. Did editing remain inside the requested scope?
10. Does the final payload contain only video/audio instructions?

Never emit this checklist inside the final H3 payload.
