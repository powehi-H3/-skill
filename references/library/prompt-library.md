# Prompt Library

A Prompt Library stores validated prompt artifacts, not general prose examples.

A prompt enters this library only after its output behavior has been validated for the intended H3 task.

## Entry requirements

Each entry records:

- task
- mode
- references and roles
- prompt
- validation status
- known limitations

A library prompt is a reference for structure and wording. It is not permission to copy its semantics into unrelated requests.
