# Experience Library

Experience is stored separately from Prompt Library.

## Lifecycle

CANDIDATE
→ VALIDATED
→ APPROVED
→ REVOKED / SUPERSEDED / STALE

Only APPROVED experience explicitly approved by the user may influence future prompt generation.

## Experience can change

- wording strategy
- ordering
- continuity strategy
- failure avoidance
- method selection

## Experience cannot change

- user intent
- reference roles
- requested characters
- requested actions
- requested setting
- requested dialogue
- other semantic facts not supplied by the current user

A successful generation does not automatically create an approved experience.
