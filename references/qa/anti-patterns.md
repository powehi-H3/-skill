# Anti-patterns

These are known failure patterns.

- Treating examples as authorization.
- Filling every schema field with invented details.
- Rewriting unrelated content during a narrow repair.
- Turning a successful sample into a default rule.
- Copying every attribute from a reference asset.
- Adding camera movement because it sounds cinematic.
- Adding lighting, props, emotions, or dialogue because they seem plausible.
- Replacing concrete H3 instructions with plot summary.
- Mixing internal reasoning into the final payload.
- Calling offline structural PASS a real H3 runtime PASS.
